## 📖 Overview

A modern, highly aesthetic, fully responsive, and **data-decoupled** personal portfolio website for **Arpan Basak**, designed with a clean **Muted Champagne Gold & Deep Bottle Green** aesthetic system.

### Key Highlights
- **Single-File Content Management**: All personal details (bio, skills list, project details, certificate/achievement cards, social links) are stored in [`js/data.js`](js/data.js). Editing your info requires updating only that single file—no HTML/CSS changes needed!
- **Refined Palette**: Muted champagne-gold background (`#F4EFE6`) paired with readable deep charcoal typography (`#1F1B16`) and deep bottle green accents (`#1B4332`).
- **Designed for Impact**: Features a custom horizontal achievement showcase tailored for 2–4 high-impact highlights so the section looks well-proportioned and deliberate.
- **Zero Heavy Dependencies**: Built with vanilla HTML5, CSS3, and JavaScript — high performance, instant page loads, and zero complex build steps.

## ⚙️ How to Edit Your Personal Data

All content is loaded dynamically from [`js/data.js`](js/data.js).

To update your portfolio:
1. Open `js/data.js`.
2. Edit any field (`personal`, `about`, `skills`, `projects`, `achievements`, `education`, or `contact`).
3. Commit and push to GitHub — Vercel will automatically redeploy your live site!

### Example: Adding a New Project in `js/data.js`
```javascript
{
  id: "my-new-app",
  title: "My New Web3 App",
  description: "Description of what this project does...",
  technologies: ["React", "Soroban", "TypeScript"],
  githubUrl: "https://github.com/arpanbasak90-cyber/my-new-app",
  liveUrl: "https://my-new-app.vercel.app",
  featured: true
}
```

## 🛠️ Running Locally

```bash
# Clone repository
git clone https://github.com/arpanbasak90-cyber/My_Portfolio.git

# Navigate into directory
cd My_Portfolio

# Start a local static web server
python -m http.server 8080
```
Open `http://localhost:8080` in your web browser.
